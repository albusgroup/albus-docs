title: API reference

---

Look up an operation's exact request and response shape. The API reference pages
are generated from the OpenAPI snapshot published with the current production
release: every operation with its request and response schemas, error bodies, and
a runnable playground. Prefer it over inferring a shape from an example.

<Note>
The snapshot is promoted by the release workflow after the matching backend
revision is deployed, so it can lag a merged change by one release. Where the
guides and the generated reference disagree, the guides describe the current
contract.
</Note>

Base URL: `https://albus.sh/api`. Both credentials are sent as
`Authorization: Bearer <value>` — see [Authenticate](/getting-started/authenticate).

For an agent or a code generator, download the [OpenAPI
document](/openapi/openapi.yaml) directly. The [SDKs](/reference/sdks) and the
[CLI](/reference/cli) are generated from that same snapshot, so an operation here
exists in all of them under the same name.
