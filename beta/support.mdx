Email [carlo@albus.sh](mailto:carlo@albus.sh). There is no ticket system in the
private beta, and that address reaches someone who can change the platform.

Ask about:

- **Access** — send the Google address you sign in with.
- **More runs** — the cap is [20 per organization](/beta/limitations).
- **A limitation that blocks you** — this is what orders the roadmap.
- **A bug** — include what makes it reproducible.

## What to include for a failed run

```bash
albus status
albus sessions get support-1234
albus sessions audit support-1234 --limit 50
```

Send the session id, the invocation key of the run (the `invocation_key` field in
the run's output), and the audit output. Between them they identify the run, the
agent revision it used, and where it stopped — and the key is what reads its
trace back, `GET /traces/{invocation_key}`.

Never send an API key, a secret value, or a provider key. Albus never asks for
one — secret values cannot be read back out of the API at all.
