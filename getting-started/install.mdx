---
title: Install
description: Install the albus CLI, and the Python or TypeScript SDK.
---

Install the client you will call Albus with. The CLI is the fastest way to run a
session and the only way to sign in with a browser; the SDKs are for calling the
API from your own code.

## CLI

`albus` is a Python package and needs Python 3.11 or newer. The installer picks
`uv`, `pip --user`, or `pip` inside a conda environment, in that order.

<CodeGroup>

```bash macOS / Linux
curl -fsSL https://albus.sh/install.sh | sh
```

```powershell Windows
irm https://albus.sh/install.ps1 | iex
```

```bash uv
uv tool install albus-cli
```

```bash pip
pip install --user albus-cli
```

</CodeGroup>

Pin a version by setting `ALBUS_CLI_VERSION` on the shell that reads the script,
not on `curl`:

```bash
curl -fsSL https://albus.sh/install.sh | ALBUS_CLI_VERSION=0.3.1 sh
```

Confirm the install, then sign in:

```bash
albus --version
albus login
```

If `albus` is not found, the install directory is not on your `PATH` — usually
`~/.local/bin`. Open a new shell, or add it.

## SDKs

<CodeGroup>

```bash Python
pip install albus-sdk
```

```bash TypeScript
npm install @albus-ts/sdk
```

</CodeGroup>

The Python SDK needs Python 3.10 or newer; the TypeScript SDK needs a runtime
with ECMAScript 2020 or newer (Node.js 18+, Bun 1+, Deno 1.39+). Both are
generated from the same [OpenAPI
contract](https://docs.albus.sh/openapi/openapi.yaml) as the API reference and
default to `https://albus.sh/api`. They authenticate with an API key, which you
mint after signing in — see [Authenticate](/getting-started/authenticate).
Read [SDKs](/reference/sdks) for authentication, responses, and errors.
