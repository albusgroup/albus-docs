---
title: Albus
description: Run agent sessions over an HTTP API — a CLI, two SDKs, MCP tools, and organization-scoped secrets.
---

Albus runs an agent for you. You send a prompt and an agent configuration; Albus
executes the model loop in an isolated environment, connects the MCP servers you
declare, and returns the assistant's reply. A session keeps its history, so the
next prompt continues the conversation.

<Note>
Albus is in **alpha**, by invitation, with a cap of 20 session runs per
organization. Read [what alpha does not do yet](/alpha/limitations) before you
build on it.
</Note>

## Run your first session

<Steps>
  <Step title="Get access">
    Alpha is invite-only. [Request access](/getting-started/access).
  </Step>
  <Step title="Install the CLI">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/albusgroup/albus-cli/master/install.sh | sh
    ```
  </Step>
  <Step title="Sign in">
    ```bash
    albus login
    ```
  </Step>
  <Step title="Run">
    ```bash
    albus sessions run my-first-session \
      --prompt "In one sentence, what is a session?" \
      --agent-name demo \
      --model gemini-3.6-flash
    ```
  </Step>
</Steps>

No model API key of your own is needed for that run — Albus provides the default
model. See [Run your first session](/getting-started/first-session) for the same
thing in Python, TypeScript, and cURL.
